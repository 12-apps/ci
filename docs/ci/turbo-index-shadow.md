# Advisory Build index shadow — FUT-2360

Placement: engine observation mechanism; consumer enrollment and append-only
evidence remain in Future Pay. No accepted ADR is contradicted.

Default adoption of ci172 remains rejected. Its 8/8 useful-hit control added
1.774 seconds; zero-hit frequency alone never establishes eligibility or cash.
This experiment changes no normal restore, Build, save, lane verdict or gate.
GitHub can prepare/download referenced actions even for disabled steps;
default-false does not prove zero preparation overhead. Measure that before
considering a release. This engine PR remains an unmerged experiment.

The optional enrollment is false by default. A consumer probe enrolls one normal
Build through a comment-only change in a real Build input; it does not disable
the existing fingerprint or force a full suite. Normal PR checks remain.

Hard explicit observer-step envelope: four minutes, consisting of a
one-minute clean-overlay check before restore, two minutes for observation and
one tiny-cache upload/lookup/restore, and one minute for post-Build inventory.
The dry-run is bounded at 30 seconds plus five seconds termination grace,
32 MB output, 100,000 inventory entries and a 4 MB raw index. No additional
payload restore, dependency install or Build repetition occurs. GitHub action
preparation is outside these step timers; record it separately. The normal
Build job's existing 45-minute timeout remains unchanged. Four minutes is not
a bound on all incremental cost, an invoice estimate or ordinary-check cost.

The before observation derives a receipt index from the current materialized
normal restore's exact matched key and compares all actual planned hashes.
The original ci172 predicate is retained, with additional unknown-overlay and
observer-environment fallbacks. Missing/stale/malformed/wrong indexes, unknown
versions/environments, empty/incomplete graphs, useful/partial/non-executable
intersections and symlinked/unsupported inventories retain restore. Private
predicate controls on the actual graph execute without another Build.

Raw Turbo JSON may contain configured secrets. It stays in an owned 0700
temporary directory in a 0600 file, is removed finally, and is neither printed
nor uploaded. Evidence contains identities, counts, sizes, decisions and
observer-only CPU/I/O, not environment values. Observer errors warn and never
alter the exit status of normal Build. Test failures still fail normally.

The one tiny cache-service round-trip uses an `index-shadow-` namespace and an
owned temporary file. Lookup and restore must both hit, and downloaded bytes
must match their SHA-256. It measures real same-job backend transport, **not**
deployed cross-job producer/index pairing, legacy-index adoption or current
invoice savings. Producer inventory/serialization/compression is observed on
already-produced normal output; no production index is published. The actual
normal off-PR save condition is retained. Join consumers' exact matched keys
to a fixed observation window for observed fan-out; future fan-out stays unknown.

Current per-archive sizes are measured without decompressing the payload and
must not be attributed to the inaccessible historical 1.45 GB object. Nested
observer timers are not added again to assigned job time. Cache-service step
timings/compressed object bytes and normal Build task counts must be read from
actual logs. No default or selective production adoption is established merely
by a green shadow. Repeated net comparisons and zero useful/fallback regression
remain required. Actual billing/paid-host lifetimes are needed for dollars/50%.

Rollback for this unmerged probe: set enrollment false and restore the normal
consumer `@v2` call; remove only the comment-only probe input. Leave the small
probe object to ordinary cache expiry; do not delete shared caches. No merge,
release, ready transition, auto-merge, infrastructure or spending policy change
is authorized. Consumer evidence cites E-056 and the all-cache closeout.

the protocol for selective production adoption. Representative eligibility and
fan-out, actual paired producer upload/discovery, repeated net comparisons and
real useful/partial/unknown fallback zero-regression evidence remain required.

review is pending. Current billing, paid-host idle and instance price data are
